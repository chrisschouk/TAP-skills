# Coverage log

Every hit recorded the same way, so the report writes itself.

## When to use

- A review, feature, interview, or playlist add has landed.
- A client asks "what did we get?"
- A campaign is ending and needs a wrap.

## Procedure

1. **Record the hit.** Outlet, date, headline, link, and type: review, feature,
   interview, playlist, radio, or social.
2. **Note the reach only if it is published.** If the outlet does not publish
   numbers, leave it blank. Do not estimate.
3. **Separate earned from owned.** Earned is coverage you did not control. Owned is
   your own channels. Never count owned as press.
4. **Pick the strongest hit** and say why in one sentence. Usually the one with the
   most relevant audience, not the biggest name.
5. **Name the gap.** Which target did not land, and what that suggests for next
   time.

## Guardrails

- Never inflate a number. A "reach" figure with no source is not a number.
- Never count a social repost as press coverage.
- Never describe a playlist add as editorial support unless the outlet says so.
- If a link is dead, record it and mark it dead. Do not quietly drop it.

## Output

The hit list with type and link, earned and owned counted separately, the strongest
hit with the reason, and the gap.
